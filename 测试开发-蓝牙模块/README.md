## 目标

玩家操作的 STC-B 学习板通过**蓝牙透传模块**（UART TTL，9600 8N1）把按键操作
**直接**传到上位机（笔记本蓝牙虚拟 COM）。协议沿用既有 3 字节帧族
（上行 `AA 01/02 掩码`、下行 `AA D1/D2 HP`），**PC 端程序零改动**——启动时用
既有 `--p1/--p2` 显式指定蓝牙 COM 即可（自动扫描跳过蓝牙口是既有设计）。

- 蓝牙为**全双工**：除上行按键外，还支持下行 LED 血量条与命中/结束音效（同有线/485 手柄）。
- 每块手柄板一条独立链路（形态 = 有线双 COM 的无线版）。

## 与正式版既有接法的关系

| 方案 | 板→PC 链路 | PC 数据口 | 下行 LED |
|---|---|---|---|
| ① 485 三板（主推） | 手柄→485→中转板→USB | 1 | ✅ 经中转板转发 |
| ② 有线 USB | 手柄 USB 直连 | 2 | ✅ |
| ③ 红外无线 | 手柄→红外→接收板→USB | 1 | ❌ 无下行 |
| **④ 蓝牙（本次测试）** | **手柄 UART2→蓝牙模块→PC 蓝牙** | **2（每板一个蓝牙 COM）** | **✅ 直达** |

## 快速开始（详见 02_测试文档）

```bat
:: 1) 编译：Keil 打开 01_蓝牙手柄固件 下 BT_Player1/2.uvproj → F7
::    产物在 HEX\BT_Player1.hex / BT_Player2.hex
:: 2) 烧录：STC-ISP，STC15F2K60S2，11.0592MHz，烧完关闭 STC-ISP
:: 3) 接线+配对（见 接线与模块配置.md），笔记本蓝牙各出一个 COM
:: 4) 裸链路自测
cd 02_上位机程序
python tools/serial_probe.py COMx
:: 5) 进游戏（示例：玩家2 蓝牙 + 玩家1 有线板）
python main.py --p1 COM3 --p2 COM6
```
