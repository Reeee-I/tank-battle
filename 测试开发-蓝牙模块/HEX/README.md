# 蓝牙测试期 HEX 输出目录

> 本目录是**蓝牙测试开发**（`测试开发-蓝牙模块/`）的 Keil 输出目录，
> 仅存放测试期编译产物；正式目录（根目录 `HEX\`）在测试期内不做任何改动。

| HEX 文件 | 工程 | 用途 / 烧到哪块板 | 数码管身份 |
|---|---|---|---|
| `BT_Player1.hex` | `测试开发-蓝牙模块/01_蓝牙手柄固件/BT_Player1.uvproj` | 蓝牙手柄1（玩家1，EXT 口 UART2 外接蓝牙模块 → PC 蓝牙虚拟 COM） | **1** |
| `BT_Player2.hex` | `测试开发-蓝牙模块/01_蓝牙手柄固件/BT_Player2.uvproj` | 蓝牙手柄2（玩家2，同上） | **2** |

- 编译：Keil 打开 `01_蓝牙手柄固件` 下对应 `.uvproj` → F7（Output 已指向本目录）。
- 烧录：STC-ISP，型号 **STC15F2K60S2**、频率 **11.0592MHz**（外部晶振，与 SysClock 一致）；
  烧完务必关闭 STC-ISP，避免 COM 被占用。
- LED 语义与既有玩家手柄板一致：L0~L5 = 所控坦克血量条（满血3=6灯、掉血灭右侧、死亡全灭，
  上电默认全灭），身份看数码管 1/2。
- 测试完成后整理：按根目录 `03_文档/08_整理记录/整理说明.md` 的规则把两个 `.hex`
  迁入根目录 `HEX\`（届时更新 `HEX\README.md` 对照表），本目录随之归档/删除。
