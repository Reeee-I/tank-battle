# HEX 统一输出目录（对照表）

> 本目录是 **本项目所有 Keil 工程的统一 HEX 输出目录**。
> 各工程 Keil Output Directory 均已指向本目录（MCU 工程为 `..\HEX\`，
> 无线与 485 工程为 `..\..\HEX\`），在此编译即可直接产出命名统一、
> 含义清晰的 `.hex` 文件，方便区分与上板测试。

## 文件 ↔ 板子用途对照

| HEX 文件 | 工程 | 用途 / 烧到哪块板 | 数码管身份 | LED 说明（v2.8） |
|---|---|---|---|---|
| `485_Player1.hex` | `485手柄\RS485_Handle1.uvproj` | **485 手柄1**（玩家1 从机，485 总线被点名应答，经中转板转发 PC） | **1** | 血量条 L0~L5（默认全灭） |
| `485_Player2.hex` | `485手柄\RS485_Handle2.uvproj` | **485 手柄2**（玩家2 从机，485 总线被点名应答，经中转板转发 PC） | **2** | 血量条 L0~L5（默认全灭） |
| `485_Relay.hex` | `485手柄\RS485_Hub.uvproj` | **485 中转板**（485 轮询主机 + USB/串口1 原样转发 PC，主推方案的第三块板） | **C** | 转发成功时 L0 亮（工作指示，非血量） |
| `USB_Player1.hex` | `MCU\TankBattle_P1.uvproj`（或双 Target 的 Player1） | **有线玩家1** 手柄板（旧方案：USB 直连 PC，仍可选） | **1** | 血量条 L0~L5（默认全灭） |
| `USB_Player2.hex` | `MCU\TankBattle_P2.uvproj`（或双 Target 的 Player2） | **有线玩家2** 手柄板（旧方案：USB 直连 PC，仍可选） | **2** | 血量条 L0~L5（默认全灭） |
| `IR_Player2.hex` | `无线手柄\HEX_A_IR_Tx\HEX_A.uvproj` | **无线发送端 HEX-A**（玩家2无线手柄，红外发射，无需接 PC） | **A** | L7 常亮（无下行通道，本期不做血量） |
| `IR_Relay.hex` | `无线手柄\HEX_B_IR_Rx\HEX_B.uvproj` | **无线接收端 HEX-B**（红外接收 + 串口1 转发，USB 接 PC） | **b** | 转发成功时 L0 闪（工作指示，非血量） |

> **v2.8 起 LED 语义**：两块玩家手柄板（485 / 有线）的 **LED(L0~L5) = 所控坦克血量**——
> 满血3=6灯、每掉 1 血灭右侧 2 灯、死亡全灭；**上电/未进对局默认全灭**，由 PC 下行帧
> `AA D1/D2 HP` 驱动（开局/命中/回血/死亡/重开时下发，重插自动补发）。身份一律看
> **数码管最左位**（1/2/C/A/b）。旧版"上电亮 L0/L7 作身份"已被取代；无线方案无下行
> 通道，本期维持原 LED 用法。

## 数码管身份速查（一眼区分各板角色）

| 显示 | 含义 |
|---|---|
| **1** | 玩家1 手柄板（485 方案 或 旧 USB 直连方案均可，靠所烧 HEX 名区分用途） |
| **2** | 玩家2 手柄板（同上） |
| **C** | 485 中转板（485_Relay：485 轮询主机 + USB 转发 PC，主推方案第三块板） |
| **A** | 无线发送端（HEX-A，红外发射，替代玩家2 手柄） |
| **b** | 无线接收端（HEX-B，红外接收后经 USB 转发给 PC） |

> 说明：'1'/'2' 同时见于 485 手柄与旧有线手柄（玩家身份语义本就一致，靠所烧
> HEX 名区分用途）；'A'/'b'/'C' 段码是在各工程 `main.c` 的 `decode_table[]`
> 中追加（索引 26/27/28），属用户可自定义译码表，与 BSP 兼容。

## 本目录里的其它文件

Keil 编译时除 `.hex` 外还会在本目录生成中间文件：
`main.obj`（各工程同名，编译时互相覆盖属正常）、`*.lnp`、`*.plg`、
`*.hex` 外的无扩展名中间文件。这些都可忽略；**只有七个 `.hex` 是烧录用文件**。
如需清理，删除除 `.hex` 外的文件即可，不影响下次编译。

## 重新编译后如何取用

1. 改完某工程代码 → 在 Keil 中 F7 编译（Output 已指向本目录）；
2. 到本目录取对应 `.hex`（见上表）；
3. STC-ISP 烧录：型号 **STC15F2K60S2**，频率 **11.0592MHz**（外部晶振，与 `SysClock` 一致）；
4. 烧完务必 **关闭 STC-ISP**，否则 COM 口被占用，游戏无法打开。
