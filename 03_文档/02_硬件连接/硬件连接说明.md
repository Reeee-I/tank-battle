# 硬件连接说明（三种方案）

> 所有板子：**STC-B 学习板（STC15F2K60S2）**，板载 USB（CH340 → 串口1，P3.0/P3.1）。
> 通用前提：9600bps 8N1；供电与数据口以各方案说明为准。

---

## 方案① RS485 三板手柄（主推）

```
[手柄1板]──┐                              ┌─ UART2/485 轮询主机 ─┐
[手柄2板]──┼── RS-485 共享总线(A/B/GND) ──→│  中转板(第三块板)      │── USB/串口1 ──→ PC
  被点名才应答   9600bps 8N1 半双工        │  点名P1→收→点名P2→收  │   9600bps 8N1
```

接线步骤：

1. **485 总线**：三块板的 485 接口 A 并 A、B 并 B，成一条总线
   （端子丝印通常 A/A+、B/B-）；
2. **共地**：三块板 GND 相连（若都由同一电脑 USB 供电则已天然共地，仍建议显式共地）；
3. **终端电阻**：总线最远两端各跨接一个 **120Ω** 电阻（看板面跳线/焊盘；短距离桌面
   演示可先不加，不通再补）；
4. **供电**：中转板板载 USB **必须接 PC**（唯一数据口）；两块手柄板板载 USB 仅供电
   （充电头/充电宝/PC 其它 USB 口均可）。

| 板 | 所烧 HEX | 角色 | 数码管身份 |
|---|---|---|---|
| 手柄1 | `HEX\485_Player1.hex` | 485 从机，点名码 E1 应答 | **1** |
| 手柄2 | `HEX\485_Player2.hex` | 485 从机，点名码 E2 应答 | **2** |
| 中转板 | `HEX\485_Relay.hex` | 485 轮询主机 + USB 转发 PC | **C** |

## 方案② 有线 USB 直连（可选，旧方案）

```
[手柄1板]──USB──→ PC（COMx）        [手柄2板]──USB──→ PC（COMy）
```

- 每块板一根 USB 线直连电脑（板载 CH340 → 串口1），即得两个 COM 口，最简；
- 备用接法：用 EXT 扩展口 UART2（P1.1 TXD2 → USB-TTL 模块 RX，GND 共地），
  需另购 USB-TTL 模块；此时把 `01_有线模式/main.c` 的宏 `UART_IF` 改为 1 重编
  （纯上行，无 LED 下行通道）。
- > 使用板载 USB 同时外接 USB-TTL 仅作监听时，保证两者共地、不要两路同时供电。

| 板 | 所烧 HEX | 角色 | 数码管身份 |
|---|---|---|---|
| 板1 | `HEX\USB_Player1.hex` | 有线玩家1 | **1** |
| 板2 | `HEX\USB_Player2.hex` | 有线玩家2 | **2** |

## 方案③ 红外无线（可选）

```
[HEX-A 发射板]     红外(38KHz NEC)      [HEX-B 接收板]       串口1(USB)       [PC 游戏]
 玩家2无线手柄   ───────────────────→  IR_RXD 收包校验    ──────────────→  自动绑定为玩家2
 (导航键+K1/K2)    IR_TXD → IR_RXD       AA 02 xx 原样转发  9600 8N1
```

- 玩家1 仍用原有线手柄板（`HEX\USB_Player1.hex`，接线不动）；
- 玩家2 用无线方案：HEX-A 发射（手柄，数码管 **A**）→ 红外对准 → HEX-B 接收转发
  （数码管 **b**，USB 接 PC）；距离 0.2~3 米、中间无遮挡；
- HEX-A 供电可用任意 USB 口（5V），**不需要连电脑**；
- 上电顺序建议：先 HEX-B（转发板），再 HEX-A（手柄）。

## 方案④ 蓝牙无线（当前正式路线：BT05 BLE 桥接，2026-09-07 定稿）

```
[蓝牙手柄板]                        PC（Windows，需一次配置 VSPD+依赖）
 按键→UART2(EXT)                  ┌───────────────────────────────────────┐
   → BT05(BLE 0xFFE0/FFE1)        │ bleak ← ble_bridge.py ← COM21          │
   ←←←←← BLE 无线 ←←←←←←←←←←←←←← │   （VSPD 虚拟串口对 COM20⇄COM21）         │
                                  │ COM20 → 游戏 main.py --p1 COM20 --p2 COM4│
                                  └───────────────────────────────────────┘
```

- **模块**：BT05（CC2541 BLE 透传），接板 **EXT 口 UART2**（TTL）：
  模块 RXD←板 TXD2(P1.1)、模块 TXD→板 RXD2(P1.0)、GND 共地、VCC 取板 5V；
- **板**：烧 `HEX\BT_Player1.hex`（玩家1，数码管 **1**）或 `BT_Player2.hex`
  （玩家2，数码管 **2**）；板载 USB **仅供电**（充电头/充电宝），不连电脑数据；
- **PC 端为何有桥接**：BT05 是 BLE，Windows 不会给它生成 COM；
  需 VSPD 虚拟串口对 COM20⇄COM21 + `02_上位机程序/tools/ble_bridge.py`
  把 BLE 字节流搬成普通 COM（详见 `01_下位机程序/05_蓝牙模式/README.md`）；
- **上电/使用顺序**：板子上电 → 双击根目录 `启动蓝牙对战.bat`
  （自动：开桥接→等链路→开游戏）；连不上就板子断电 3 秒重上电。
- 蓝牙为**全双工**：上行按键 + 下行 LED 血量条/音效都支持（游戏实测通过）。

> 备选（仅存档）：若有 HC-05/HC-06 **经典蓝牙 SPP** 模块，Windows 直接生成
> COM（无需 VSPD/桥接），接线同上（模块换 HC-05/06），配对见
> `测试开发-蓝牙模块` 归档文档（git 历史）与 05_蓝牙模式 README 第八节。

## 各方案对比速查

| 项目 | ① 485 三板（主推） | ② 有线 USB 直连 | ③ 红外无线 | ④ 蓝牙无线（BT05 BLE 桥接） |
|---|---|---|---|---|
| PC 数据口数量 | 1（中转板） | 2（每板各一） | 1（HEX-B） | 2（虚拟 COM20/21） |
| 手柄是否需要接 PC | 否（仅供电） | 是 | 否（仅供电） | 否（仅供电） |
| LED 血量条下行 | ✅ 支持（经中转板转发） | ✅ 支持 | ❌ 无下行通道（LED 全灭属正常） | ✅ 支持（BLE 全双工直达） |
| PC 额外要求 | 无 | 无 | 无 | 装 VSPD 建 COM20/21；`tools/_bleak_deps/` |
| 对应固件目录 | `01_下位机程序/02_RS485模式/` | `01_下位机程序/01_有线模式/` | `01_下位机程序/03_红外模式/` | `01_下位机程序/05_蓝牙模式/` |

> 通用提示：烧录用 STC-ISP，型号 **STC15F2K60S2**、频率 **11.0592MHz**
> （外部晶振，与 `SysClock` 一致）；烧完务必**关闭 STC-ISP**，否则 COM 被占，
> 游戏打不开。
