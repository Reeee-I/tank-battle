# 使用说明（双人坦克对战）

> 分三部分：PC 端运行、板端编译与烧录、验收清单与 FAQ。

## 一、PC 端运行

### 环境要求
- Windows 10/11，Python 3.8+；安装依赖：
  ```bat
  cd 02_上位机程序
  pip install -r requirements.txt      :: pygame、pyserial
  ```

### 运行
```bat
python main.py                          :: 自动扫描串口并按包内容绑定玩家
python main.py --p1 COM3 --p2 COM5      :: 手动指定两个串口（485 单口：两参写同一中转 COM）
python main.py --no-keyboard            :: 纯手柄模式（默认含键盘调试控制）
python main.py --debug                  :: 打印按键 / 重开 / 下行帧诊断
```

### 操作
| 动作 | 板子（手柄） | 键盘（调试/备用） |
|---|---|---|
| 开始（启动后） | 任一手柄任意键 | 任意键 / 鼠标点击 |
| 前进 / 后退 | 导航键 上 / 下（按住持续） | 玩家1 W/S；玩家2 ↑/↓ |
| 左转 / 右转 | 导航键 左 / 右（按住持续） | 玩家1 A/D；玩家2 ←/→ |
| 开火 | K1（按下瞬间） | 玩家1 空格；玩家2 回车 |
| 重开（对局结束后） | **任一手柄按 K2**（或鼠标点击） | 鼠标点击 |
| 退出 | — | Esc |

### 串口状态提示
画面顶部每玩家有 **绿点=在线 / 橙点=断开 / 灰点=未绑定**；某玩家超 0.6s 未上报 →
显示"断开!"并冻结其输入（不清生命不判负），每 2s 自动重连，恢复后自动回来。

### 烧录后先验链路（不开游戏）
```bat
python tools/serial_probe.py            :: 监听所有串口实时打印解析结果
python tools/serial_probe.py COM3 COM5  :: 只监听指定串口
```

### 自测
```bat
python tests/test_logic.py              :: 逻辑自测（30 项，无需 pygame/串口）
python tests/test_maps.py               :: 地图约束自测（4 项 + 平衡回归）
python tests/test_serial_e2e.py         :: 串口链路端到端（12 项，虚拟串口）
python tests/acceptance_sim.py          :: 验收标准 1~8 自动化预演
python tests/visual_qa.py               :: 画面 QA（截图到 tests/shots/）
```

### 蓝牙手柄（当前正式无线路线 · BT05 BLE + VSPD 桥接）使用步骤

> 前提（一次性，见 `01_下位机程序/05_蓝牙模式/README.md`）：蓝牙板已烧
> `HEX\BT_Player1.hex`（或 BT_Player2.hex）；PC 已装 **VSPD** 并建好
> **COM20 ⇄ COM21** 虚拟串口对；`tools/_bleak_deps/` 已就绪。

**每次使用（推荐，一键）**
1. 蓝牙手柄板接充电头/充电宝**上电**（不插电脑数据线），数码管显示 1；
2. **双击项目根目录 `启动蓝牙对战.bat`**：自动 ① 开 BLE 桥接 → ② 等链路就绪
   （≤45 秒）→ ③ 启动游戏（玩家1=蓝牙手柄，玩家2=COM4 有线板，可改参数）；
3. 45 秒没连上？→ 蓝牙板**断电 3 秒重上电**再双击一次。

**手动模式（不用 bat）**
```bat
:: 窗口1：BLE 桥接（保持运行）
cd 02_上位机程序\tools
python ble_bridge.py --com COM21 --addr 00:15:83:F0:15:97
:: 窗口2：游戏
cd 02_上位机程序
python main.py --p1 COM20 --p2 COM4
```

> ⚠️ **不要直接 `python main.py` 不带参数**：自动扫描发现不了 VSPD 虚拟口
> （且本就跳过蓝牙类口），玩家会一直"没有连接"。蓝牙必须显式 `--p1 COM20`
> （玩家2 有线板插着就加 `--p2 COM4`，没插就用键盘）。日常最省事 = 双击
> 根目录 `启动蓝牙对战.bat`（自动带全参数，并先替你启动桥接）。

**游戏内操作**与有线手柄一致：导航键移动/转向、K1 开火、对局结束 K2 重开、
K3 可开始；拔蓝牙板电源约 0.6s 显示"断开!"，恢复上电自动重连。
LED 血量条、命中/结束音效均正常（蓝牙全双工支持下行）。

**日常排障**：桥接窗口提示"扫不到模块"→ 蓝牙板断电重上电一次；仍不行 → 设置→
蓝牙和其他设备 删除 BT05 配对后再断电重上电板子。详见
`01_下位机程序/05_蓝牙模式/README.md`。

## 二、板端：编译与烧录

### 编译（Keil uVision4 + C51，芯片 STC15F2K60S2）
1. 打开对应方案目录下的 `.uvproj`（工程均已配置好共享头文件 / 库 / 输出目录）：

| 想编的 HEX | 打开工程 | 说明 |
|---|---|---|
| `USB_Player1.hex` / `USB_Player2.hex` | `01_下位机程序/01_有线模式/TankBattle.uvproj` | 双 Target，Batch Build 一次出两个；也可用 `TankBattle_P1/P2.uvproj` 单编 |
| `485_Player1.hex` | `01_下位机程序/02_RS485模式/RS485_Handle1.uvproj` | Define `PLAYER_ID=1` |
| `485_Player2.hex` | `01_下位机程序/02_RS485模式/RS485_Handle2.uvproj` | Define `PLAYER_ID=2` |
| `485_Relay.hex` | `01_下位机程序/02_RS485模式/RS485_Hub.uvproj` | 中转板 |
| `IR_Player2.hex` | `01_下位机程序/03_红外模式/01_发射端/HEX_A.uvproj` | 红外发送端 |
| `IR_Relay.hex` | `01_下位机程序/03_红外模式/02_接收端/HEX_B.uvproj` | 红外接收转发 |
| `BT_Player1.hex` | `01_下位机程序/05_蓝牙模式/BT_Player1.uvproj` | 蓝牙手柄1（Define `PLAYER_ID=1`） |
| `BT_Player2.hex` | `01_下位机程序/05_蓝牙模式/BT_Player2.uvproj` | 蓝牙手柄2（Define `PLAYER_ID=2`） |

2. 按 F7 编译（Output 已指向 `HEX\`），产物取自上表文件名的 `.hex`。
3. 新建工程时逐条核对：Include Paths = `..\common\inc;..\04_音效模块`
   （红外子目录两层 `..\..\`）；加入 `common\STC_BSP.lib` 与
   `04_音效模块\sound_effect.c`（如需音效）；Memory Model = Small、
   Optimize = Level 8；Output 指向根 `HEX\`。

### 烧录（STC-ISP）
1. 型号选 **STC15F2K60S2**；频率 **11.0592MHz**（外部晶振，与 `SysClock` 一致）；
2. 载入对应 `.hex` → 下载/编程（必要时按提示给板上电）；
3. 上电验证身份：数码管最左位 1 / 2 / C / A / b 对应各角色；
4. 烧完**关闭 STC-ISP**，否则 COM 被占用游戏打不开。

## 三、验收清单（三族固件通用操作）

| # | 验收项 | 操作 |
|---|---|---|
| 1 | 身份区分 | 板1/板2 上电数码管最左位显示 1 / 2 |
| 2 | 移动 | 导航键 → 对应坦克移动/转向 |
| 3 | 开火 | K1 → 发射子弹（按住不连发） |
| 4 | 命中 | 命中对方 → 对方 -1 命、自己 +10 分、对方回出生点并短暂无敌 |
| 5 | 胜负 | 任一方生命归零 → 中央显示"玩家X 获胜！" |
| 6 | 障碍物 | 坦克无法穿过灰色障碍；子弹碰障碍消失 |
| 7 | 重开 | 对局结束后点击鼠标 或 任一手柄 K2 → 恢复初始重开 |
| 附 | 断线提示 | 拔某板 → 状态变橙"断开!"；插回自动恢复 |
| 8 | LED 血量联动 | 开局满血 6 灯；被命中灭 2 灯；血包回血补亮；死亡全灭；K2 重开回满血 |

## 四、FAQ

- **找不到串口 / 提示无可用串口**：查 USB/驱动（CH340）；关闭占用端口软件（尤其 STC-ISP）。
- **能开端口但坦克不动**：先跑 `tools/serial_probe.py`：无包 → 查烧录、数码管 1/2、
  波特率 9600；有包不动 → 确认窗口活动、方向语义（板子上=前进）。
- **身份反了/错乱**：自动绑定以第一个收到的合法包为准，也可 `--p1/--p2` 手动指定。
- **开枪没反应**：K1 为按下瞬间单发，一下一下按；同屏最多 3 发、冷却 200ms。
- **中文变方块**：缺中文字体，安装微软雅黑/黑体后重试。
- **编译报错**：核对 Include 路径与 `STC_BSP.lib` 是否在工程内、型号与 Target 配置；
  确认库与 `inc/` 头文件同版本。
- **改波特率/频率**：PC 端 `serial_handler.py` 的 `BAUDRATE`、板端 `Uart1Init/Uart2Init`
  与 `SysClock` 需三者一致。
- **重开无反应**：只有"鼠标点击 / 任一手柄 K2"两种；仍不行用 `python main.py --debug`
  复现并把控制台 / `02_上位机程序\debug_keys.log` 相关行发回定位。
- **找不到 USB_Player2.hex**：双 Target 工程默认编 Player1；切 Target 或 Batch Build，
  或直接开 `TankBattle_P2.uvproj`。
- **485 接好但没反应 / 只显示一个玩家**：看数码管 1/2/C；跑 `serial_probe.py` 看中转 COM
  是否交替出现两玩家包（~10Hz 各一包）；查 A/B 是否接反、共地、波特率、STC-ISP 是否关闭。
- **手柄 LED 血条不动/全灭**：确认烧 v2.8+ 固件；接法须有下行通道（有线直连 / 485 /
  **蓝牙**）；**红外无线无下行通道，LED 全灭属正常**；开始界面未进对局时全灭也属正常。
- **蓝牙手柄连不上（桥接窗口一直扫模块）**：蓝牙板断电 3 秒重上电（BT05 上电才广播）；
  仍不行 → 设置→蓝牙和其他设备 **删除 BT05 配对**，再断电重上电板子一次。
- **打开 COM20 报错/没这口**：VSPD 的 COM20⇄COM21 没建好或服务没起：打开 VSPD
  主界面 Add pair 重建/Apply。
- **两个玩家都想用蓝牙**：需要第二块 BT05、第二对 VSPD 端口与第二个桥接实例，
  见 `01_下位机程序/05_蓝牙模式/README.md` 第六节"双蓝牙双玩家"。
